- `scripts/heavy_run.sh`'s shared lease has two slots. `MIMIR_HEAVY_TIER=medium` holds one, so two medium commands (tests, verifies, builds) can share the host; `large`, the default and the old behaviour, holds both and runs alone, and a waiting large command blocks new medium ones so measurements aren't starved. A holder from an older helper, which records no tier, counts as large. Worklink forwards a valid tier to builder sessions, gates and `repo_test` legs alongside the lease path and timeout, and fails closed on any other value.
